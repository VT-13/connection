Connection is an early product idea. Joining the interest list lets its maker contact you about product progress, research, and possible early access. Joining does not create a product account or guarantee access.

This project page

GitHub Pages hosts this page. GitHub logs visitor IP addresses for security. Fonts load from Google Fonts, which receives ordinary network requests. This page does not use advertising cookies or store email addresses in GitHub.

The interest list

The join button opens Connection’s existing sign-up site, hosted through OpenAI Sites with Cloudflare database infrastructure. That site stores your email, when you joined, campaign labels from the link, and any optional use-case answer. Authorized administrators can export the list to manage updates. Hosting providers may process ordinary request logs under their own policies.

Your choice

Connection updates must include a personal unsubscribe link. Using it removes your email and sign-up details from the active list. The maker must honor that removal in exported mailing lists before sending further updates. Backups and provider logs may have separate retention periods.
